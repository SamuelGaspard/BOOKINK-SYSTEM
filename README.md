"Agis en tant qu'expert développeur Full-Stack et UX Designer. Je souhaite créer une application web de Système de Réservation de Rendez-vous (Booking System) moderne, intuitive et robuste. L'application doit comporter deux interfaces distinctes : une pour les clients et une pour les administrateurs/prestataires.

1. Fonctionnalités Clients (Frontend)

•
Recherche et Sélection : Interface pour choisir un service, un membre du personnel et un créneau horaire disponible en temps réel.

•
Profil Utilisateur : Création de compte, historique des réservations, gestion des rendez-vous à venir (annulation/report).

•
Paiement Intégré : Possibilité de payer un acompte ou la totalité via Stripe ou PayPal.

•
Notifications : Confirmation par email et rappels automatiques.

2. Interface Administrateur (Dashboard)

•
Gestion du Calendrier : Vue d'ensemble des rendez-vous (jour, semaine, mois) avec possibilité de glisser-déposer.

•
Configuration des Services : Ajouter/modifier des prestations (nom, durée, prix, description).

•
Gestion du Personnel : Définir les horaires de travail, les pauses et les congés pour chaque employé.

•
Analyses et Rapports : Tableau de bord affichant le chiffre d'affaires, le taux d'occupation et les statistiques de fréquentation.

3. Spécifications Techniques

•
Stack Technologique : Utilise React (Vite) pour le frontend, Node.js pour le backend, et une base de données relationnelle (MySQL/PostgreSQL) avec un ORM comme Drizzle ou Prisma.

•
Design : Utilise Tailwind CSS pour un design "Mobile First", propre et professionnel.

•
Sécurité : Authentification sécurisée (JWT ou OAuth), protection contre les doubles réservations (concurrence) et conformité RGPD.

4. Livrables attendus

•
Une architecture de base de données optimisée.

•
Une interface utilisateur fluide avec des animations de transition.

•
Un code propre, modulaire et documenté."
